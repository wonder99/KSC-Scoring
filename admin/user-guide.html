Admin Dashboard User Guide

The 701 Club Admin Panel - Complete Usage Instructions

Overview

This user guide provides detailed instructions for accessing and using the The 701 Club admin dashboard. The admin panel allows authorized administrators to manage scores, teams, and match schedules for the darts league.

Note: This dashboard requires an ADMIN_API_KEY to access. Make sure you have the correct key before proceeding.

How to Access the Admin Dashboard

To access the admin dashboard, follow these steps:

1

Open your web browser and navigate to the main application URL.

2

Locate the admin login section - This is typically found in the top navigation bar or footer of the website.

3

Enter your ADMIN_API_KEY when prompted. This key is required for authentication and should be provided by the system administrator.

4

Click Login to access the admin dashboard interface.

Security Warning: Never share your ADMIN_API_KEY with unauthorized users. Keep it secure and rotate keys periodically for security.

Main Dashboard Tabs

The admin dashboard is organized into three main tabs, each serving a specific purpose:

Score Review Tab

This tab allows you to view, edit, and delete scores for matches. It displays a comprehensive list of all recorded scores with options for management.

Key Features:

  • View all current scores in a sortable table format
  • Edit existing scores directly
  • Delete incorrect or duplicate scores
  • Recalculate scores if needed
  • Refresh the score list to see updates

Team Management Tab

This tab allows you to manage teams participating in the league. You can add new teams, view existing teams, and remove teams when needed.

Key Features:

  • Add new teams with player information
  • View all current teams and their rosters
  • Delete teams that are no longer participating
  • Manage team members and player assignments

Schedule View/Edit Tab

This tab allows you to view the current season schedule and make edits to upcoming matches.

Key Features:

  • View upcoming matches in a grid format
  • Edit match details including date, time, and venue
  • Delete matches that are no longer needed
  • Add new matches to the schedule
  • Refresh the schedule to see updates

Detailed Function Instructions

Score Review Tab

The Score Review tab displays a table of all recorded scores. Here's how to use it:

Viewing Scores:

  • All scores are displayed in a table format with date, teams, and scores
  • Click the "Refresh" button to update the score list

Editing Scores:

To edit a score:

  1. Locate the score you want to edit in the table
  2. Click the "Edit" button for that row (note: actual editing functionality is implemented in the dashboard)
  3. Make your changes and save them

Deleting Scores:

To delete a score:

  1. Locate the score you want to delete in the table
  2. Click the "Delete" button for that row
  3. Confirm the deletion when prompted

Recalculating Scores:

To recalculate a score:

  1. Locate the score you want to recalculate in the table
  2. Click the "Recalculate" button for that row
  3. The system will recompute the score based on current rules

Team Management Tab

The Team Management tab allows you to manage all teams in the league:

Adding New Teams:

To add a new team:

  1. Fill out the "Add New Team" form with team details
  2. Enter the team name
  3. Add players (at least one player required, up to two players)
  4. Click "Add Team" to submit the form

Viewing Teams:

  • All teams are displayed in a table format
  • Shows team name and list of players
  • Use the refresh button to update the team list

Deleting Teams:

To delete a team:

  1. Locate the team you want to delete in the table
  2. Click the "Delete" button for that row
  3. Confirm the deletion when prompted

Schedule View/Edit Tab

The Schedule View/Edit tab displays upcoming matches in a grid format:

Viewing Matches:

  • Upcoming matches are displayed in cards with date, time, teams, and venue
  • Use the "Refresh Schedule" button to update the display

Editing Matches:

To edit a match:

  1. Locate the match you want to edit in the grid
  2. Click the "Edit" button for that match
  3. Make your changes and save them (note: actual editing functionality is implemented in the dashboard)

Deleting Matches:

To delete a match:

  1. Locate the match you want to delete
  2. Click the "Delete" button for that match
  3. Confirm the deletion when prompted

Troubleshooting Tips

If you encounter issues while using the admin dashboard:

  • Ensure your ADMIN_API_KEY is correct and has not expired
  • Try refreshing the page if data doesn't load properly
  • Check that you have proper permissions to perform the requested action
  • Contact system administrator if issues persist
Tip: All actions in the admin dashboard are logged for security purposes. If you make changes, they will be recorded.

Best Practices

  • Always verify data before making edits to ensure accuracy
  • Use the "Refresh" buttons to make sure you're working with current information
  • Confirm deletions before proceeding, as they cannot be undone
  • Keep your ADMIN_API_KEY secure and never share it with unauthorized users
  • Document major changes made in the admin panel for future reference
