701 Club Reports

User Guide for Accessing and Understanding League Statistics

How to Access the Public Reports Website

The 701 Club reports website is accessible through a public URL that can be shared with all members. To access the reports:

  1. Open your web browser (Chrome, Firefox, Safari, Edge, etc.)
  2. Navigate to the public URL: https://the-701-club-reports.vercel.app
  3. Wait for the page to load completely

Note: The reports website is updated automatically with the latest league statistics. All data is refreshed regularly to ensure accuracy.

Overview of Available Reports

The 701 Club reports website provides several different types of statistical information:

Standings

Shows the current league standings with team positions and points.

  • Team names
  • Points earned
  • Wins, losses, and draws
  • Current position in the league

Men's Stats

Detailed statistics for male players including averages and performance metrics.

  • Overall performance statistics
  • Average scores
  • 95+ scores
  • Outs information

Ladies' Stats

Detailed statistics for female players including averages and performance metrics.

  • Overall performance statistics
  • Average scores
  • 95+ scores
  • Outs information

Leaders

Shows top performers in various categories across the league.

  • Top scorers
  • Best averages
  • Consistent performers
  • League leaders in different metrics

Navigating Between Tabs and Sections

The website features an intuitive tab-based navigation system that allows you to easily switch between different reports:

  1. Use the main navigation tabs at the top of the page:
    • Standings - For current league positions
    • Men's Stats - For detailed male player statistics (dropdown menu for sub-tabs)
    • Ladies' Stats - For detailed female player statistics (dropdown menu for sub-tabs)
    • Leaders - For top performers in various categories
  2. For Men's Stats and Ladies' Stats, click on the dropdown arrow next to each tab to access detailed sub-reports:
    • Overall - Complete player statistics
    • Avg - Average scores
    • 95+ - Number of 95+ scores
    • Outs - Information about outs
  3. Click on any tab to view the corresponding statistics immediately

What Each Report Shows

Standings

The Standings report displays the current league position of all teams in the 701 Club. This includes:

  • Team names and their current positions
  • Total points earned by each team
  • Win, loss, and draw records
  • Points difference between teams

Men's Stats

The Men's Stats report provides detailed performance data for male players:

  • Overall: Complete player statistics including total points, wins, losses, and other metrics
  • Avg: Average scores for each player
  • 95+: Number of times each player has scored 95 or higher
  • Outs: Information about outs and their impact on performance

Ladies' Stats

The Ladies' Stats report provides detailed performance data for female players:

  • Overall: Complete player statistics including total points, wins, losses, and other metrics
  • Avg: Average scores for each player
  • 95+: Number of times each player has scored 95 or higher
  • Outs: Information about outs and their impact on performance

Leaders

The Leaders report highlights top performers across different categories:

  • Top scoring players in the league
  • Players with the best averages
  • Most consistent performers
  • League leaders in various statistical categories

Important: All data is automatically updated and reflects the most recent league statistics. The website refreshes regularly to ensure you always have access to the latest information.

Additional Information and Tips

  • All reports are displayed in a clear, easy-to-read table format
  • Tables are sortable by clicking on column headers
  • Some reports may take a moment to load when first accessed
  • For best viewing experience, use desktop or laptop browsers
  • Mobile-friendly design allows access on smartphones and tablets

If you encounter any issues accessing the reports or have questions about the data, please contact the league administrators for assistance.
