GROUP A: Stale row-number formulas on non-weekly summary sheets
========================================================================

Errors #1–#10 (positions A19, A20, A22, A29, A30, A32, A39, A40, A41, A51)

Problem: These positions are row counters. 22 of 27 sheets correctly use
'=A{n-1}+1' but the other 5 non-weekly sheets have stale cross-sheet refs
from W1 when it was first created and never corrected.

Dissenting sheets (always the same ones):
  - Leaders:      ='Mens 95'!A{row}
  - Mens Overall: ='W1 - Team Master'!<wrong_column>5
  - Mens Outs:    ='W1 - Team Master'!<wrong_column>5
  - Mens Avg:     ='W1 - Team Master'!<wrong_column>5
  - Mens 95:      ='W1 - Team Master'!<wrong_column>5

Impact: Row numbering is broken on these 5 sheets — cell A19 might show the
value from W1's BR5 instead of incrementing from A18. This cascades wrong to
all downstream formulas that rely on row numbers.

Fix needed: Change all dissenting cells in Leaders, Mens Overall, Mens Outs,
Mens Avg, Mens 95 sheets from '=<something>!<col>5' to the correct
'=A{n-1}+1' pattern.

GROUP C: Wrong T# team column pasted in across weekly sheets
========================================================================

Errors #19–#84 — spans positions C19-C50, D19-D50, E3-E50, F9-F66, G19-G72, H9-H78, I9-I84

Problem: At each of these positions across the W1-W22 weekly sheets, 12 weeks have
the correct formula but 1-4 dissenting weeks reference a different T# team's column.

Pattern examples:
  Position C19 — dominant '=SUM(C13:C18)' (12 weeks)
    Dissenting:   'T12'!N185, 'T5'!S185, 'T12'!Q185, 'T12'!R183
  
  Position D9 — dominant '=SUM(D3:D8)' (12 weeks)
    Dissenting:   'T1'!O188, 'T4'!O183, and one cell is '=B9+C9'

  Position E6 — dominant '=IF(C6,D6/C6,0)' (12 weeks)
    Dissenting:   'Lady Avg'!A4, 'T2'!P185, 'T12'!P186, 'T1'!$Q$189

  Position E44 — dominant '=IF(E6=180,...)+...+IF(E10=180,...)' (22 weeks)
    Dissenting:   'T3'!P188, 'T6'!P188, 'T4'!$Q$189

Key observations:
- The dissenting sheets are always one of: T1-T12, Standings, or a Lady summary sheet
- Each position has a CONSISTENT wrong T# across all dissenting weeks (e.g., at E17, every
  dissenting week has 'T4'!P185 — it's not random)
- Error #29 also has '=B9+C9' on Standings — this is likely an inline sum that should be a
  cross-sheet reference

Cause: When adding/removing teams or copying cells between team sheets, the formula was pasted
from a different team sheet (e.g., T4 instead of T5), so all dissenting weeks point to the same
wrong team column.

Impact: Scoring for one team gets mixed with another team's data — scores appear under the wrong
team name and totals are incorrect.

Fix needed: For each position, identify which T# column is correct (based on which team actually
occupies that roster position), then update all dissenting cells to reference the correct T#.
